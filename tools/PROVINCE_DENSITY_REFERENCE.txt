Flusion Ecumenopolis — province_density.png reference
=====================================================

Paint province_density.png in grayscale.

  RGB 128,128,128 = 1.0x default province AREA (legacy/default size)
  RGB   0,  0,  0 = 0.1x default AREA (10x as many provinces locally)
  RGB 255,255,255 = 10.0x default AREA (1/10 as many provinces locally)

The scale is logarithmic in AREA.
Gray sea still uses the normal large sea target; gray land still uses the normal land target.

Interpretation examples
-----------------------
  0.5x area = provinces aim for half their ordinary local area (~2x density).
  2.0x area = provinces aim for twice their ordinary local area (~1/2 density).
 10.0x area = maximum sparse setting.
  0.1x area = maximum dense setting.

The layer changes target province AREA, not terrain, areas, regions, or impassability.
Impassable provinces remain one province per connected impassable component.

A missing province_density.png or a perfectly uniform 128-gray file uses the old
neutral generation path exactly.
